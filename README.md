# ConfereJus
Programa de auditoria jurídica que parte de um documento concreto, identifica suas teses e avalia se as jurisprudências (futuramente doutrinas também) realmente à sustentam. Em vez de apenas localizar decisões, compara a força das fontes e dos argumentos e realiza recomendações (mantê-las, complementá-las ou substituí-las.
